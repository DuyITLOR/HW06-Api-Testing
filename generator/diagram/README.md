# Sơ đồ generator — PHẢI TỰ VẼ

§11 (Anti-AI-Cheat) ghi đích danh: *"The AI test-generator diagram, which must be self-drawn —
designed by you, not generated directly by an AI."* TA kiểm mục này khi chấm.

**Cách làm:**
1. Đọc `generator/design.md` §3 (6 giai đoạn) — đó là thiết kế **của sinh viên**.
2. Tự vẽ bằng công cụ nào cũng được (draw.io / Excalidraw / Figma / vẽ tay rồi chụp). Đề cho phép
   *"any diagramming tool is fine"* — điều bị cấm là **để AI sinh ra hình**.
3. Lưu ở đây với tên `generator-flow.png` (và file nguồn `.drawio`/`.excalidraw` nếu có, để chứng
   minh là mình vẽ).
4. Nhúng vào `generator/design.md` §4 và `report/main-report.md` §10.

**Đừng** để AI xuất Mermaid rồi render thành hình và nộp như sơ đồ tự vẽ — đó đúng là thứ §11 cấm.
